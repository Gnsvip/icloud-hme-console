iCloud HME Cookie Helper

安装方法：
1. 解压 icloud-hme-cookie-helper.zip。
2. 打开 Chrome 扩展程序页面：chrome://extensions/
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 icloud-hme-cookie-helper 文件夹。
5. 登录 iCloud.com.cn 或 iCloud.com。
6. 点击扩展图标，选择地区，点击“生成 Cookie”。
7. 点击“复制 Cookie”，回后台“导入 iCloud Cookie”里粘贴并校验。

说明：
- 扩展只读取 iCloud / Apple 相关 Cookie，并显示为 Header String。
- Cookie 等同登录凭证，只粘贴到自己的后台，不要发给别人。
