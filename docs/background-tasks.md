# 工作台后台任务

确认删除后弹窗立即关闭，任务提示位于工作台顶部，可切换页面继续操作。完成或部分失败时显示通知，点击“查看详情”核对逐项结果。确认内容、登录验证码、Apple 条款、生成链接结果及表单输入继续在原交互中完成。

支持后台执行的操作：

- 云端别名删除（沿用原有服务器删除队列）
- 永久删除垃圾箱记录（批量保存一次，保留删除标记，防止同步重新加入）
- 云端同步、iCloud 查件、转发查件、云端校准
- 邮箱状态修改、恢复、移入垃圾箱、云端标签、本地备注
- 账号连接校验、收件箱云端刷新
- 手动补货、批量撤销取码链接、历史日志清理
- 批量创建本来就在服务器执行，现增加跨页进度与结束通知

后台维护任务由 `POST /api/background-tasks` 接收，传入 `request_id`、`title`、`steps`。每个步骤包含 `path`、可选 `body`、`method` 和显示用 `label`。仅允许服务端明确列出的操作；账号添加、密码修改、登录、任意 URL 和任务接口自身不能通过此入口执行。所有任务接口均要求管理员会话。

`GET /api/background-tasks/active` 返回排队和执行中的任务，`GET /api/background-tasks/<job_id>` 返回进度和结果。同一提交标识重复发送不会重复执行，进行中的相同操作也会合并。队列串行执行维护操作，最多 8 个待完成任务，每次最多 500 个步骤。单项失败不会掩盖其他项的结果；失败项不会自动重试。

刷新页面后继续查询已保存的任务标识，也会恢复服务器上尚未完成的任务。任务在服务器进程内执行，关闭浏览器不会取消已接收任务；完成记录最多保留 30 分钟、50 个任务。服务重启会清除任务记录，页面会提示核对结果，绝不会自行重新执行。部署前必须确认创建任务、云端删除队列和 `/api/background-tasks/active` 均空闲。

测试使用临时库存和模拟网络，不删除真实邮箱或垃圾箱数据。
